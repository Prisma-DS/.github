# Quienes somos 
En Prisma DS ayudamos a las empresas a tomar decisiones con información clara y confiable. Somos una consultoría de datos especializada en reportes, modelado y automatización con Power BI, apoyada en bases de datos SQL (PostgreSQL y Oracle) y Python.

# Qué hacemos
- Dashboards e informes en Power BI a medida
- Integración y organización de datos desde bases de datos, Excel y otras fuentes
- Automatización de reportes y pipelines de datos
- Capacitación para equipos que quieren usar sus propios reportes
